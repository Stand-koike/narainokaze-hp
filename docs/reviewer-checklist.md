# Reviewer Checklist

> **目的:** Builder / Animation 完了後の品質確認を標準化する。  
> **工程位置:** Builder → Animation → **Reviewer（本ドキュメント）** → Performance → Deploy  
> **関連:** 構造化・固定幅予防は [builder-workflow.md](builder-workflow.md)。動きは [animation-guide.md](animation-guide.md)。

---

## 確認対象

| 対象 | パス |
|------|------|
| 開発 | `src/index.html` / `src/pages/*.html`（HTTP サーバー経由） |
| 本番相当 | `dist/*.html`（`npm run build` 後） |
| ページ | TOP + 全下層 |

`file://` 直開きは使わない。プロジェクトルートで `py -m http.server 8080` 等を起動する。

---

## レスポンシブ確認（必須）

DevTools の端末幅（または実機）で、**TOP + 下層各ページ**を見る。

| 幅 | 目安 | 見るポイント |
|----|------|-------------|
| **375px** | スマホ | 横スクロールなし、はみ出し、タップ領域、テキスト折り返し |
| **768px** | タブレット | 余白・カラム崩れ、ナビ折り返し |
| **1366px** | ノート PC | Header / main / Footer の横幅一致 |
| **1920px** | 大画面 | 同上 + `max-w-[1440px]` 中央寄せの破綻なし |

### チェック項目

- [ ] 375px / 768px / 1366px / 1920px で **横スクロールが発生しない**
- [ ] Header・main・Footer の幅が揃い、段差やはみ出しがない
- [ ] Hero / CTA の absolute 背景・オーバーレイが画面幅に追従する（`w-[1440px]` 固定の残骸なし）
- [ ] 固定幅コンテンツ（例: `w-[640px]`）が狭い画面ではみ出さない、または `max-w` / パディングで収まる
- [ ] ナビ・CTA・電話リンクがモバイルでもタップ可能
- [ ] 画像がコンテナを壊さない（極端な縦伸び・はみ出しなし）
- [ ] `src/` で問題なければ `dist/` でも同幅を再確認する（公開前）

### 報告時の書き方

問題があれば **Critical / Improvement** に分け、次を書く。

- ページ URL（またはファイル）
- 再現幅（例: 375px）
- 原因（クラス・要素）
- 推奨対応（デザイン意図を壊さない範囲）

## その他の品質確認

レスポンシブ以外も Reviewer でまとめてよい。

### リンク・画像

- [ ] ナビ・内部リンク・CTA が切れていない
- [ ] 画像 404 がない（Network）
- [ ] `alt` が空の意味ある画像がない（装飾は例外可）

### SEO・見出し

- [ ] 各ページに固有の `<title>` と `meta description`
- [ ] ページ主見出しが `<h1>`（1 ページ 1 つ）
- [ ] 以降の見出し階層がおおむね妥当（`<h2>` 中心）

### アクセシビリティ・動作

- [ ] キーボードで主要リンク・FAQ 等にフォーカスできる
- [ ] フォーカスが見える
- [ ] アニメーションが `dist` で動く（`page:ready` 非依存）
- [ ] `prefers-reduced-motion: reduce` で過剰な動きが抑制される

### ビルド成果物

- [ ] `dist` に `{{...}}` や未置換プレースホルダが残っていない
- [ ] `load-data.js` / `load-sections.js` が `dist` HTML に含まれていない

## Builder との分担

| 項目 | Builder | Reviewer |
|------|---------|----------|
| シェルの `w-full max-w-[1440px]` 化 | ○（予防） | ○（回帰確認） |
| 1366 / 1920 の横幅一致 | ○（完了判定に含む） | ○ |
| **375 / 768 の端末確認** | ×（責務外） | **○（必須）** |
| デザインのモバイル再設計 | × | 指摘のみ（実装は別依頼） |

Builder 完了チェックに「デスクトップ幅の整合」があっても、**スマホ／タブレットの目視は Reviewer 完了の条件**とする。

---

## 完了の定義

次を満たしたら Reviewer 完了とする。

1. 上記レスポンシブ必須チェックを TOP + 全下層で実施した
2. Critical がゼロ、または修正済みで再確認済み
3. 公開前は `dist/` でもレスポンシブを一度通した
