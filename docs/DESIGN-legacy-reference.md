# DESIGN.md — 下田ベイクロシオ

公式サイトの見た目・挙動をコーディングAIが再現するためのデザインシステム要約。実装は WordPress テーマ `baykuro`（`common.css` / `top.css`）に基づく。

---

## 1. Visual theme and atmosphere（ビジュアルテーマと雰囲気）

**What**  
伊豆・下田の海を一望する温泉リゾート宿。ビジュアルは「高級ホテルの派手さ」より、**自然の光・海・和の余白**に寄せた落ち着き。

**Why**  
コピー「やさしい自然に包まれる、小さな幸せ。」と一致させ、**特別感を叫ばず、静かな幸福感**を伝える。写真（海辺・露天・料理）が主役で、UIは**補助線**に徹する。

**態度・トーン**  
- 丁寧・柔らか・説明過多にしない。  
- 英語ラベル（Rooms / Hot Spring 等）は装飾ではなく**セクションのリズム**として使う。  
- **リゾート＋和**（畳・懐石・温泉）であり、南国リゾートのノリだけに寄せない。

| | `on.inverse` | `#FFFFFF` | 濃色・ブランド色の上の文字 |

### 配色の考え方

- **主役は写真**。UI色は `#71BAC3` と `#3D4849` で静かに支え、大面积塗りは避ける。
- **冷色（海）＋暖色（#F29B7B）** の2軸。ゴールド等の第三色は使わず、暖色アクセントに統一。
- **濃色UI** は `#1c2b3e` 系のネイビーではなく `#2E5660`（ブランド深み）で海と調和させる。

**禁止に近い使い方**  
- 蛍光・原色のピンク/黄緑で「バナー広告」っぽくする。  
- `brand.primary` を画面全体の大面积塗りに使い、写真を潰す。

## 3. Typography rules（タイポグラフィのルール）

| レベル | フォント | サイズ（目安） | ウェイト | 行間 | 字間 | 用途 |
|--------|-----------|----------------|----------|------|------|------|
| Body | `zen-old-mincho`, serif | `clamp(10px, 1.21vw, 16px)`（PC） / `clamp(12px, 3.59vw, 14px)`（≤959px） | 400（通常）、600（strong） | PC `2.2` / SP `1.75` | `1px` | 本文・ナビ・説明文 |
| 英字ラベル | `minerva-modern`, serif（`.minerva`） | セクションにより `min(1.06vw, 14px)` 等 | 400 | 個別指定 | 英字で `3px` 程度の箇所あり | 「Rooms」「Hot Spring」等のサブタイトル |
| セクション見出し（日） | zen-old-mincho | `min(3.33vw, 44px)`（PC） / `28px`（SP） | 400 | `1.6` | 本文に準じ | `.section_head_ja` |
| セクション見出し（英） | minerva-modern | `min(2.12vw, 28px)`（PC） / `min(5.13vw, 20px)`（SP） | 400 | `1.15` | — | `.section_head_en`、色は `brand.primary` |
| ヒーロー見出し | 同上系統 | トップでは `min(3.33vw, 44px)` 前後〜大きめ可変 | 400 | 該当ブロックに合わせる | — | ファーストビューのキャッチ |

**Rationale**  
- **明朝で「和」と「滞在の長さ」**を支え、欧文は **minerva-modern** でリゾートのクラシック感を足す。  
- **vw＋clamp** でブレークポイント間も滑らかに。960px 前後でモバイル用タイポに切り替わる。

## 4. Component styles（コンポーネントスタイル）

### 4.1 ヘッダー

- 固定配置、`z-index: 99`、高さ **120px**（スクロール時はテーマ側でクラス変化あり）。  
- ロゴは PC で縦ロゴ SVG、狭い画面では横ロゴ（`picture` の `media` 切替）。

### 4.2 「もっと見る」系（`.btn_more_link`）

- テキスト＋**左の円形アイコン**（矢印）。  
- アイコン：`border: 1px solid #AAA`、`border-radius: 9999px`（完全な円）。  
- **Hover（`hover: hover` のみ）**: 背景 `#71BAC3`、矢印白 SVG、枠 `#71BAC3`。  
- トランジション：`transition: all 0.2s`。

### 4.3 セクション見出しブロック（`.section_head`）

- 日本語見出しの下に英語1行、英語色 **`#71BAC3`**。  
- 下マージン：`min(4.55vw, 60px)`（PC）、SP は `min(10.26vw, 40px)`。

### 4.4 汎用ボタン・タグ（トップ）

- 白文字＋背景 `#444`＋枠 `#444` のボタン、ホバーで反転など（`top.css` の CTA 系）。  
- 別パターン：背景 `#71BAC3` または `#F29B7B` の帯・ボタン（用途に応じて）。

### 4.5 フォーム（Contact Form 7）

- プラグイン既定＋テーマ上書き。フォーカスリングはサイト全体で `*:focus { outline: none; }` のため、**アクセシビリティを上げる実装では focus-visible を別途付与**することを推奨。

### 4.6 状態まとめ

| 状態 | 目安 |
|------|------|
| Hover | 0.2s、色は brand 系へ、矢印・枠の一体変化 |
| Focus | 現状 outline なし → 要改善前提で設計するなら `outline: 2px solid #71BAC3` を検討 |
| Disabled | サイト固有の定義が薄い → 不透明度 0.4＋`pointer-events: none` を推奨 |

## 5. Layout principles（レイアウトの原則）

| 項目 | 値 | Rationale |
|------|-----|-----------|
| コンテナ最大幅 | `max-width: 1320px`（`.inner`） | ワイド画面でも行長が読みやすい範囲に |
| 横ガター | `padding: 0 clamp(20px, 3.03vw, 40px)` | 端の余白を画面幅に応じて確保 |
| メイン下余白 | PC `padding-bottom: 220px` / SP `120px` | 固定フッター・CTAとの干渉を避ける |
| 主要ブレークポイント | **959px**（多くのコンポーネント）、**1199px**（ヘッダー周り一部） | 「タブレット以下」でナビや余白が切り替わる |
| 角丸 | CTA は `9999px`（ピル型）、一部 `2px`（タブ状） | 円＝「誘導」、小さな角丸＝「情報」 |

## 6. Depth and elevation（奥行きとエレベーション）

| Level | 用途 | 指定（例） |
|-------|------|------------|
| 0 | フラットな面 | 影なし、`#fff` / `#F0FDFF` |
| 1 | 軽い浮き（パネル） | `box-shadow: 0 4px 20px rgba(0,0,0,.1)` |
| 2 | より手前（モーダル・ドロワー付近） | `box-shadow: 0 6px 20px rgba(0,0,0,.1)` |

**Rationale**  
マテリアルの「重ね」より**写真と余白**で奥行きを出す。影はごく弱く、リゾートの「静けさ」を壊さない。

## 7. Do's and don'ts（すべきこと・避けるべきこと）

### Do

- **海・空・和の余白**を前提に、タイポは読みやすさ優先（行間 2.2 前後）。  
- **日英二段のセクションタイトル**（和文＋英字で色 `#71BAC3`）を踏襲する。  
- **写真はフルブリード**気味に使い、UI色と競合させない。  
- CTA は **円形矢印＋ティールのホバー**という既存パターンを再利用する。

### Don't

- **強いグラデーション・ネオン・ガラスモーフィズム**で「テック系LP」にする。  
- **純黒 `#000`** の多用、または **primary の大面积塗り**で写真を沈める。  
- **サンセリフ体だけ**で全体を固め、和文の雰囲気を失う（英字ラベル以外は明朝系を尊重）。  
- **狭い画面で文字を詰めすぎる**（SP では行間 1.75 に切り替わる前提）。  
- **過剰なドロップシャドウ**でカードが「重い」印象になる。

## 8. Responsive behavior（レスポンシブの挙動）

| ブレークポイント | 主な挙動 |
|-------------------|----------|
| `> 959px` | 横並びレイアウト、PC 用ロゴ、本文 `clamp(10px, 1.21vw, 16px)`、行間 2.2 |
| `≤ 959px` | `.onlypc` 非表示 / `.onlysp` 表示、行間 1.75、タップ向けにボタン円を大きく（例：52px）など |
| `≤ 1199px` | ヘッダー内のレイアウト調整（該当ブロック） |

| 項目 | 推奨 |
|------|------|
| タッチターゲット | 円形 CTA は SP で **最低でも 26〜52px 程度**（ブロックにより異なる）— **44px 以上**を確保する実装が望ましい |
| ヒーロー | ビューポートに応じた `min()` / `vw` でタイトルサイズ調整 |
| 横スクロール | `overflow` を増やしすぎない（`.main` は `overflow: hidden` あり） |

## 9. Agent prompt guide（エージェントプロンプトガイド）

### Quick palette（コーディング用一行メモ）

```
背景: #FFFFFF / #F0FDFF / #FBF8F5  |  テキスト: #3D4849 / #888888  |  ブランド: #71BAC3  |  濃色: #2E5660  |  暖色: #F29B7B
欧文ラベル: minerva-modern  |  本文: zen-old-mincho  |  コンテナ max 1320px  |  breakpoint 959px
```

### コンポーネント作成プロンプト例

**例1：トップのヒーロー直下に「客室」導線ブロックを追加**  
「下田ベイクロシオ公式サイト（baykuro.co.jp）に合わせ、`.section_head` 相当の見出し（日本語＋英語 Rooms）を置き、英語行は色 `#71BAC3`、フォントは minerva-modern。本文は zen-old-mincho、行間広め。CTA は円形矢印の btn_more スタイル（枠 #AAA、ホバーで #71BAC3 塗り）。背景は白または #F0FDFF。」

**例2：お知らせ一覧カード**  
「カード背景 #fff、境界線は #D9D9D9、影は `0 4px 20px rgba(0,0,0,.1)` まで。日付は #888。リンクホバーでテキスト色を #71BAC3 に。」

**例3：予約ボタン**  
「主要アクションは背景 `#71BAC3`、文字白。副次は枠 `#444` 塗り `#444`。角丸はピル型（大きな border-radius）か、サイト既存のボタンに合わせる。」
